| Домен                       | Ответственность                                                                      | Данные, которыми владеет домен                                                                                       | Обоснование                                                                                                                                                                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Медицина                 | Все, что связано с оказанием медицинских услуг.                                      | Медицинские карты, истории болезней, расписание врачей, данные исследований, инвентаризация медикаментов.            | Выделение в отдельный домен позволяет изолировать его от рискованных изменений в других доменах (например Финтех). Этот домен является источником самых ценных и чувствительных данных, но не местом для их свободной аналитики.                                                                                                |
| 2. Финтех                   | Финансовые продукты и услуги для клиентов.                                           | Счета, кредиты, транзакции, финансовая история клиента.                                                              | Финтех-рынок требует максимальной скорости вывода новых продуктов (time-to-market). Команда этого домена должна иметь возможность ежедневно выкатывать обновления, не оглядываясь на медицинский блок. Разделение гарантирует, что запуск нового вида кредита не потребует доработок в DWH и не сломает систему записи к врачу. |
| 3. ИИ-Сервисы               | Разработка и применение моделей ИИ.                                                  | Модели для постановки диагнозов, скоринговые модели, алгоритмы анализа данных.                                       | Этот домен носит в большей степени исследовательский характер. Его требования — гибкость в экспериментах и доступ к большим объемам данных. Выделение в домен позволяет им использовать любые инструменты и подходы, не затрагивая "боевые" системы. Их независимость критична для создания инноваций.                          |
| 4. Корпоративное управление | Обеспечение работы всей компании как единого целого.                                 | Данные по персоналу (HR), сводная финансовая отчетность, общая инвентаризация (кроме медицины), управление доступом. | Выделение в отдельный домен позволяет избежать дублирования. Например, вместо того чтобы в "Медицине" и "Финтехе" были свои списки сотрудников, будет единый централизованный сервис в домене "Корпоративное управление", который является единым источником правды                                                             |
| 5. Платформа данных         | Технический домен, отвечающий за сбор, хранение и предоставление данных для анализа. | Озеро данных (Data Lake), Облачное DWH, инструменты трансформации (ETL/ELT).                                         | Это служебный домен, который обеспечивает взаимодействие всех остальных. Его задача — предоставить единый, стандартизированный способ обмена данными (через события) и их анализа (через "витрину данных").                                                                                                                     |
